# Documentation site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish `docs/` as a Blume site at https://alekzonder.github.io/onecheck on every release.

**Architecture:** `docs/` becomes a Blume project whose content root is `docs/` itself with `superpowers/` excluded. Links between pages are site routes (`/checks`). `make docs` builds and pushes `docs/dist` to branch `docs`, served by GitHub Pages; the release workflow runs it.

**Tech Stack:** Blume 1.0.4 (Node 22, npm), POSIX/bash scripts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-24-docs-site-design.md`

## Global Constraints

- `deployment: { base: "/onecheck", site: "https://alekzonder.github.io" }`.
- `content.root: "."`, exclude `superpowers/**`, `node_modules/**`, `dist/**`, `**/_*`, `**/.*`.
- Internal links: root-relative site routes without base, e.g. `/checks#gt-gte-lt-lte`, `/modules/disk`. Never `*.md`.
- README links: `https://alekzonder.github.io/onecheck/<route>`.
- `make check` stays Go-only and must pass.
- Commits: `chg:`/`fix:`/`docs:` style, no attribution trailers (AGENTS.md).

## Review Focus

- A relative `.md` link reintroduced later → `make docs-build` fails naming file and line (guard test in Task 1).
- An external link ending in `.md` (e.g. gjson `SYNTAX.md`) → guard must not flag it (Task 1 test).
- A page in `docs/superpowers/` → never in `dist/` (Task 2 verification).
- An anchor that does not exist on the target page → caught by checking built `id=` attributes (Task 2 verification).
- First publish with no remote `docs` branch → script creates an orphan branch (Task 3, ported logic).

### Task 1: Link guard script

**Files:**
- Create: `scripts/docs-check-links.sh`, `scripts/docs-check-links-test.sh`

**Interfaces:**
- Produces: `scripts/docs-check-links.sh [DOCS_DIR]` — exit 0 when clean, exit 1 and prints `file:line: link` per offending relative `.md` link. Skips `superpowers/`, `node_modules/`, `dist/`, `.blume/`. A link is offending when its target (inside `](…)`) has no scheme (`http:`, `https:`, `mailto:`) and its path ends in `.md` (optionally followed by `#…`).

- [ ] **Step 1:** Write `docs-check-links-test.sh`: builds fixtures in `mktemp -d`, asserts exit 1 for `[a](checks.md)`, `[a](../checks.md#x)`; exit 0 for `[a](/checks)`, `[a](https://x/y/SYNTAX.md)`, and for a relative `.md` link inside `superpowers/`.
- [ ] **Step 2:** Run it, expect FAIL (script missing).
- [ ] **Step 3:** Implement with `grep -rnE` over `*.md`/`*.mdx`.
- [ ] **Step 4:** Run test, expect PASS.
